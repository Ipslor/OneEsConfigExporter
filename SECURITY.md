# Сообщения о безопасности

Не публикуйте действующие пароли, токены, `settings.dat` и снимки сценариев в Issues или pull requests. DPAPI-файл также следует считать чувствительным.

Если ошибка связана с раскрытием реквизитов, сначала отзовите затронутый токен/смените пароль. Для самого сообщения используйте приватный канал владельца репозитория или GitHub Private Vulnerability Reporting, если эта функция включена. Не размещайте публично детали, позволяющие получить чужие реквизиты.

В публичном отчёте используйте фиктивные данные и очищенные журналы. Защитные ограничения текущей версии перечислены в [CodeReview.md](CodeReview.md).
