# Участие в проекте

Предложения и ошибки можно описывать в Issues. Приложите версию утилиты, Windows, платформы 1С и Git, режим выгрузки и шаги воспроизведения. Удалите реквизиты и сведения о рабочих базах из приложений.

Для изменений используйте отдельную ветку и pull request. Сборка: `./build.ps1`. Тесты: `./test.ps1 -GitPath "C:\Program Files\Git\cmd\git.exe"` под пользователем с загруженным профилем Windows.

Не добавляйте настройки, токены, журналы, реальные выгрузки и тестовые артефакты. Для изменения исполнения/безопасности добавьте воспроизводимую проверку. Тесты не должны подключаться к рабочим базам или отправлять данные на GitHub.

Лицензия проекта пока не определена; предложения по её выбору обсуждаются отдельно с владельцем.
