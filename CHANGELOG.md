# История изменений

## v2.5.1 — 2026-10-09

- В пояснения ошибок Git добавлены инструкции для PowerShell и кнопки копирования отдельных команд.
- Подготовленные изменения можно сохранить коммитом или снять с индекса без изменения рабочих файлов; учтён репозиторий без первого коммита.
- Утилита не выполняет восстановительные команды автоматически и не удаляет блокировки Git.
- Внизу настроек добавлены ненавязчивые ссылки на официальный Git для Windows и GitHub.
- Добавлены проверки команд на реальных временных Git-репозиториях, включая вложенный каталог, начальную историю и специальные символы в пути.

## v2.5 — 2026-10-09

Первый публичный выпуск. Версия собрана и прошла локальные тесты перед публикацией.

- Очередь конфигураций 1С с полной и инкрементальной выгрузкой.
- Локальные Git-коммиты и отправка на GitHub как необязательные этапы.
- Настройки DPAPI, отдельные сообщения коммитов по базе/режиму и PowerShell-сценарии.
- История команд, компактный журнал Git, подсказки ошибок и живая сводка этапов.
- Защита одинаковых/вложенных каталогов и служебной метаинформации от фильтра размера.
- Проверка staged-изменений и незавершённых операций Git; изоляция среды Git.
- Атомарные настройки/отчёты, защита от конфликтов сохранения, отмена и ограничения запросов.
- Финальное ревью: [CodeReview.md](CodeReview.md).

Предыдущие сборки разрабатывались до публичного размещения; отдельные публичные релизы для них не публиковались.
